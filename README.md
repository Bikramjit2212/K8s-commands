# Kubernetes Commands Reference (K8s Commands)

A collection of commonly used **Kubernetes (K8s) commands** that I compiled during my DevOps learning journey to practice cluster management, troubleshooting, and day-to-day Kubernetes operations.

This repository serves as a quick reference guide for frequently used `kubectl` commands and helped me strengthen my understanding of Kubernetes concepts through hands-on practice.

---

## Project Overview

Kubernetes is one of the most widely used container orchestration platforms in modern DevOps environments. While learning Kubernetes, I created this repository to organize essential commands used for managing clusters and workloads.

This repository acts as a personal knowledge base and practical cheat sheet that can be used for learning, revision, and interview preparation.

---

## Features

* Collection of frequently used `kubectl` commands.
* Covers common Kubernetes administrative tasks.
* Useful for beginners learning Kubernetes.
* Helps with troubleshooting and cluster inspection.
* Quick reference for day-to-day Kubernetes operations.
* Supports interview and certification preparation.
